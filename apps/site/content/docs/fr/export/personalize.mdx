Une partie de la personnalisation se produit déjà à l'intérieur d'ADT Studio, avant même l'exportation — les polices et la taille du texte sont définies à l'étape **Storyboard**, pour tout le livre. Au-delà de cela, tout ce qui est exporté — l'Export Web, un EPUB, un package SCORM, ou les fichiers du projet eux-mêmes — vous appartient entièrement, à vous ou à votre organisation, à partir de ce moment-là. Rien n'est enfermé dans un format propriétaire : c'est du HTML pur, des packages de livre numérique et de cours basés sur des normes, ou le dossier de projet lui-même, le tout lisible et modifiable par n'importe quel outil qui comprend ces formats.

Cela signifie que l'export n'est pas un produit fini et scellé — c'est une base solide que vous êtes libre de continuer à façonner, dans l'application ou par la suite.

## Dans l'application : polices et typographie

À l'étape Storyboard, les **Paramètres de police** vous permettent d'associer des fichiers de police ou de choisir parmi Google Fonts, puis d'assigner vous-même le rôle de chaque police (titre, corps, légende, décoratif, monospace) ou de sélectionner **Analyser avec l'IA** pour que les rôles soient assignés automatiquement à partir des images de page. Les polices sont intégrées dans le package final afin qu'elles continuent de fonctionner hors ligne ; assurez-vous d'avoir le droit d'intégrer toute police que vous téléversez. Une action **Réinitialiser les polices** restaure les valeurs par défaut à tout moment.

**Les tailles de texte** forment une échelle distincte, valable pour tout le livre : une taille (mobile et bureau) par rôle — titre de chapitre, titre de section, sous-titre, corps, légende — à partir des tailles propres détectées dans le livre. Ajustez n'importe quel rôle vous-même, ou appliquez un préréglage **Tailles accessibles** pour agrandir le livre.

## Après l'export : deux façons de continuer à personnaliser

- **À la main.** Si vous ou votre équipe travaillez déjà avec du code, les fichiers exportés ne sont que des fichiers — ouvrez-les dans n'importe quel éditeur de code (VS Code, ou celui que vous utilisez déjà) et modifiez ce dont vous avez besoin : style visuel, petites corrections, interactivité supplémentaire, tout.
- **Avec un assistant de codage IA.** Des outils comme Claude Code, GitHub Copilot / OpenAI Codex, ou Gemini peuvent apporter des modifications ciblées à partir d'une description en langage clair de ce que vous voulez — utile si le codage n'est pas la compétence principale de votre équipe, ou si vous préférez simplement décrire un changement plutôt que de l'écrire. Vous (ou quelqu'un que vous faites intervenir) ouvrez les fichiers exportés et travaillez directement avec l'assistant ; cela se passe entièrement en dehors d'ADT Studio.

Le choix dépend surtout de l'aisance de votre équipe avec le code. Une équipe avec des développeurs peut préférer travailler directement dans les fichiers ; une partie prenante moins technique peut s'appuyer sur un assistant IA pour traduire une demande en modification ; d'autres peuvent simplement remettre les fichiers à un développeur ou à un prestataire. Aucune voie n'est présumée ni requise — l'export fonctionne de la même façon quoi qu'il advienne ensuite.

<Callout title="Ceci est entièrement optionnel">
Au-delà des paramètres de police et de typographie dans l'application, toute personnalisation supplémentaire dépend entièrement de vous — rien dans la validation, la distribution ou la maintenance d'un ADT n'en dépend.
</Callout>
