## Distribution

La façon dont vous livrez l'ADT exporté dépend de votre contexte :

- **Environnements hors ligne et à faible connectivité** — les ADT exportés peuvent être préchargés sur des tablettes ou partagés sous forme de fichiers. Une fois sur l'appareil, aucun accès internet n'est nécessaire.
- **Plateformes d'apprentissage** — téléversez le package SCORM vers votre LMS comme n'importe quel support de cours.
- **Hébergement web** — publiez l'Export Web sur n'importe quel serveur ; les lecteurs n'ont besoin que d'un navigateur et du lien.

## Après la distribution

Si le contenu source change ou que vous améliorez une fonctionnalité, relancez les étapes concernées et exportez à nouveau. Les versions antérieures restent dans votre dossier de projet — rien n'est perdu, et vous pouvez toujours voir ce qui a changé.
