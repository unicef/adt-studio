Pour les apprenants aveugles ou malvoyants, une image sans description est un trou dans le contenu. Cette étape génère des **descriptions d'images (texte alternatif)** pour les figures de votre livre — des descriptions contextuelles qui décrivent réellement l'image, en s'appuyant sur le contenu environnant.

## Décisions à prendre

- **Quelles images ont un sens ?** Les diagrammes, illustrations et graphiques ont besoin de descriptions. Les éléments purement décoratifs n'en ont pas besoin — une description ne ferait qu'ajouter du bruit pour les utilisateurs de lecteurs d'écran.
- **La description est-elle exacte et utile ?** Les descriptions générées par l'IA constituent un bon point de départ, mais vous connaissez l'intention pédagogique de chaque image. Révisez-les, surtout là où l'image enseigne quelque chose.

## Configurer et générer

Les légendes nécessitent que les pages de votre livre soient d'abord mises en page — si le [Storyboard](/docs/convert-pdf/storyboard) n'est pas encore terminé, l'étape vous en informe au lieu de vous laisser l'exécuter. Une fois prête, ouvrez l'étape **Légendes d'images** et définissez :

- **Niveau scolaire** — Débutant, Intermédiaire ou Avancé — afin que les descriptions correspondent au niveau de lecture de votre public.
- **Instructions personnalisées** (optionnel) — orientez le ton, l'accent ou le vocabulaire. Le remplissage automatique génère un point de départ à partir du titre, de la langue et du résumé du livre.

Un aperçu d'exemple en direct sur la droite montre à quoi ressemble une description avant que vous n'exécutiez quoi que ce soit. Une fois prêt, sélectionnez **Exécuter les légendes**.

## Réviser et modifier

Une fois les légendes générées, chaque image devient une carte que vous pouvez filtrer (**Toutes** / **Légendées** / **Décoratives**, chacune avec un compteur), rechercher par texte de légende ou identifiant d'image, et parcourir entre les pages si le livre en compte plusieurs. Sélectionnez une image pour l'ouvrir en pleine taille ; sélectionnez le texte de sa légende pour la modifier en place, avec `Échap` pour annuler et `Cmd`/`Ctrl`+`Entrée` pour enregistrer.

Marquer une image comme **Décorative** est la manière d'agir sur la première décision ci-dessus — cela exclut entièrement cette image des lecteurs d'écran et supprime le besoin de légende. Un petit point à côté de chaque identifiant d'image indique si sa légende provient de l'IA ou d'une modification manuelle, et le sélecteur de version permet de prévisualiser et de restaurer une version antérieure.
