Chaque ADT commence comme un projet : un livre, un dossier, tout au même endroit. Vous le configurez avec un court assistant — en commençant ici par votre PDF, et en terminant sur la page suivante avec vos paramètres d'extraction.

<Callout title="Pas la même chose qu'« Importer un projet »">
ADT Studio propose également une option distincte **Importer un projet**, pour rouvrir un projet que vous avez précédemment exporté sous forme de fichier `.zip`. Ce n'est pas ce que couvre cette page : importer un tout nouveau PDF. Si vous partez d'un PDF, recherchez plutôt **Convertir un PDF**.
</Callout>

## Avant d'importer

La qualité de votre ADT dépend fortement de la qualité de votre PDF source. Si ce n'est pas déjà fait, lisez [Quel type de contenu peut devenir un ADT ?](/docs/get-started/what-type-of-content) — cette page explique quels PDF se convertissent bien et ce qu'il faut vérifier avant de commencer.

<Callout title="Première fois ?">
Commencez avec un PDF court et simple (10 à 30 pages). Vous découvrirez tout le processus plus rapidement et comprendrez ce que fait chaque étape avant de travailler avec un manuel complet. Vous n'avez pas non plus besoin d'un fichier court — la page suivante vous permet de convertir seulement une plage de pages d'un PDF plus long.
</Callout>

## Importer

Choisissez **Convertir un PDF**, puis déposez votre fichier sur l'écran de téléversement (ou utilisez **Téléverser un PDF** pour le sélectionner depuis le disque) et sélectionnez **Continuer**. ADT Studio suggère un nom de projet à partir du nom de votre fichier — vous le confirmerez ou le modifierez, ainsi que le reste de vos paramètres d'extraction, sur la page suivante.

![L'écran de téléversement « Convertir un PDF », avec une zone de dépôt en pointillés pour le fichier PDF et un bouton Continuer](./import-pdf-upload.png)

Rien n'est écrit sur votre ordinateur tant que vous n'avez pas terminé cette configuration et sélectionné **Créer l'ADT**. Ce n'est qu'à ce moment qu'ADT Studio crée le dossier de projet qui contiendra le fichier source, vos paramètres, tout le contenu généré, et chaque version — le tout au même endroit.

Vous pouvez créer autant de projets que vous le souhaitez. Chacun est indépendant.

## Ce qui se passe ensuite

La page suivante, [Extraire le contenu](/docs/convert-pdf/extract), vous guide dans la configuration — puis l'exécution — de l'extraction. Si vous avez déjà une clé API enregistrée au moment où vous sélectionnez **Créer l'ADT**, l'extraction démarre automatiquement, et vous arrivez directement sur votre livre avec ce travail déjà en cours. Le [Découpage](/docs/convert-pdf/sectioning) est une étape distincte que vous exécutez ensuite vous-même.
