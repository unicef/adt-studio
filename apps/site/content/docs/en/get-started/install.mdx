ADT Studio runs locally on your computer. There are two ways to install it.

<Cards>
  <Card title="Desktop app" description="Install like any normal program — download it, double-click it, open it. The right choice for almost everyone." />
  <Card title="Docker" description="A more technical option for IT-managed environments. If the word “Docker” is unfamiliar, this option isn't for you — use the desktop app instead." />
</Cards>

<Callout title="In short">
Both desktop app and docker install give you **exactly the same features**. The only difference is how the tool gets onto your machine.
</Callout>

## Option 1: Desktop app

The desktop app is available for **Windows** and **macOS**.

<Steps>

<Step>
### Download
Go to the [ADT Studio download page](https://unicef.github.io/adt-studio/download/) and download the installer for your system.
</Step>

<Step>
### Install it
Open the downloaded file and follow the installation steps.
</Step>

<Step>
### Launch ADT Studio
Open it like any other app on your computer.
</Step>

</Steps>

## Option 2: Docker

If you are comfortable with Docker, or your organisation prefers containerised tools, ADT Studio can run in Docker with no other setup — no additional software or development tools needed.

**Requirement:** [Docker](https://docs.docker.com/get-docker/) installed on your machine.

<Tabs items={['Quick command', 'docker-compose', 'Windows launcher']}>

<Tab value="Quick command">
The quickest way is a single command in your terminal:

```
docker run -p 8080:80 -v ./books:/app/books ghcr.io/unicef/adt-studio:latest
```

Then open `http://localhost:8080` in your browser. Your book data is saved in the `books` folder next to where you ran the command.
</Tab>

<Tab value="docker-compose">
Download the `docker-compose.yml` file from the [latest release](https://github.com/unicef/adt-studio/releases/latest), then run:

```
docker compose up
```
</Tab>

<Tab value="Windows launcher">
For Windows users who want the Docker route without using the terminal: download the file `windows-setup-and-run.bat` from the [latest release](https://github.com/unicef/adt-studio/releases/latest) and double-click it. The script checks that the required software is installed (and points you to download links if not), sets everything up, and opens ADT Studio in your browser.

**Prerequisites for this option:** [Git](https://git-scm.com/download/win) and [Docker Desktop](https://www.docker.com/products/docker-desktop/).
</Tab>

</Tabs>

## Minimum requirements

{/* TO VERIFY with dev team: no official minimum requirements (RAM, disk space, OS versions) are published in the repo. The section below is a placeholder structure. */}

| Requirement | Details |
|---|---|
| **Operating system** | Windows or macOS for the desktop app. Any system that runs Docker for the Docker option. |
| **Internet connection** | Required during installation, when downloading updates, and during PDF conversion (for the AI processing). Not required to open or use a finished ADT. |
| **An AI provider API key** | Required before you can convert a PDF. See [API Keys and costs](/docs/get-started/api-keys). |

## Notes

- **Updates.** ADT Studio updates itself automatically — new versions are applied without downloading or reinstalling.
- **Building from source.** ADT Studio is open-source. Grab the code and build instructions from the [GitHub repository](https://github.com/unicef/adt-studio).
- **Something not working?** Check the [Troubleshooting & FAQ](/docs/faq) page, or [report the issue](/docs/reporting-issues).
