## Built to be trusted

Accessible book production is usually slow, manual, and easy to get wrong —
content gets re-keyed, structure gets lost, and the steps are scattered across
tools that don't talk to each other. ADT Studio brings the whole process into
one place, around three non-negotiable ideas.

<Principles />

## Transparency by default

Every prompt, every response, and every cost is something you can open and read.
When a result looks wrong, you can see exactly which call produced it, change
the inputs, and rerun — only the work that actually changed is recomputed.
