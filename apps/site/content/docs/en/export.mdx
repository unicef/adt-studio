## What this step is about

Export takes everything you produced — structured content, narration, captions, quizzes, glossary, translations — and packages it into a format that can be shared, hosted, or uploaded to a learning platform.

Your project folder remains the source of truth. You can export the same book to several formats, and re-export at any time after making changes.

## Formats

### Project Archive

The complete project folder as a single file. This is not for readers — it is for **handing off or backing up the work itself**. Someone else can open it in ADT Studio and continue exactly where you left off, with all versions and settings intact.

### Web Export

The ADT as a self-contained website. It can be hosted on any web server or opened locally, and works in any modern browser. This is the most direct way to put an ADT in front of readers, and the format used by the public ADT demos.

### SCORM Export

A package for **learning management systems (LMS)**. SCORM is a widely supported standard — if your ministry, school network, or organisation runs an LMS (like Moodle), this format lets the ADT be uploaded as course content.

### WebPub Export (Beta)

A standards-based web publication format, designed for digital reading platforms and library systems. Marked beta: it works, but is still maturing.

### EPUB Export (Beta)

The standard format for e-books, readable in most e-reader apps and devices. Marked beta: it works, but is still maturing.

## Distribution

How you deliver the exported ADT depends on your context:

- **Offline and low-connectivity settings** — exported ADTs can be preloaded on tablets or shared as files. Once on the device, no internet is needed.
- **Learning platforms** — upload the SCORM package to your LMS like any course material.
- **Web hosting** — publish the Web Export on any server; readers only need a browser and the link.

## After distribution

If the source content changes or you improve a feature, rerun the affected steps and export again. Earlier versions remain in your project folder — nothing is lost, and you can always see what changed.
