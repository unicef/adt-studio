ADT Studio runs locally on your computer. There are two ways to install it:

- **The desktop app** — the right choice for almost everyone. You install it like any normal program and open it with a double-click.
- **Docker** — a more technical option for IT-managed environments. If the word "Docker" is unfamiliar, this option is not meant for you, and that is completely fine — use the desktop app.

Both give you exactly the same features. The only difference is how the tool gets onto your machine.

| |
|---|
| **In short:** if you just want to create ADTs, use the desktop app. Everything below on Docker is for technical teams who specifically need it. |

## Option 1: Desktop app

The desktop app is available for **Windows** and **macOS**.

1. Go to the [ADT Studio releases page](https://github.com/unicef/adt-studio/releases/latest)
2. Download the installer for your system:
   - Windows: the `.exe` file
   - macOS: the `.dmg` file
3. Open the downloaded file and follow the installation steps
4. Launch ADT Studio

## Option 2: Docker

If you are comfortable with Docker, or your organisation prefers containerised tools, ADT Studio can run in Docker with no other setup — no additional software or development tools needed.

**Requirement:** [Docker](https://docs.docker.com/get-docker/) installed on your machine.

The quickest way is a single command in your terminal:

```
docker run -p 8080:80 -v ./books:/app/books ghcr.io/unicef/adt-studio:latest
```

Then open `http://localhost:8080` in your browser. Your book data is saved in the `books` folder next to where you ran the command.

Alternatively, you can download the `docker-compose.yml` file from the [latest release](https://github.com/unicef/adt-studio/releases/latest) and run:

```
docker compose up
```

### Windows one-click launcher

For Windows users who want the Docker route without using the terminal: download the file `windows-setup-and-run.bat` from the [latest release](https://github.com/unicef/adt-studio/releases/latest) and double-click it. The script checks that the required software is installed (and points you to download links if not), sets everything up, and opens ADT Studio in your browser.

**Prerequisites for this option:** [Git](https://git-scm.com/download/win) and [Docker Desktop](https://www.docker.com/products/docker-desktop/).

## Minimum requirements

{/* TO VERIFY with dev team: no official minimum requirements (RAM, disk space, OS versions) are published in the repo. The section below is a placeholder structure. */}

- **Operating system:** Windows or macOS for the desktop app. Any system that runs Docker for the Docker option.
- **Internet connection:** required during installation, when downloading updates, and during PDF conversion (for the AI processing). Not required to open or use a finished ADT.
- **An AI provider API key:** required before you can convert a PDF. See [API Keys and costs](/docs/api-keys).

## Updating ADT Studio

ADT Studio updates itself automatically. When a new version is available, it is applied without requiring you to download and reinstall the app manually.

---

## Building from source

ADT Studio is open-source software. Developers who want to run the latest development version, contribute, or build the app themselves can find the full source code and build instructions in the [ADT Studio repository on GitHub](https://github.com/unicef/adt-studio). This is not needed for normal use — the desktop app and Docker options above cover everything most people need.
