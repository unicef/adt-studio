Every ADT starts as a project: one book, one folder, everything in one place. Importing a PDF creates that project.

## Before you import

The quality of your ADT depends heavily on the quality of your source PDF. If you haven't yet, read [What type of content can become an ADT?](/docs/what-type-of-content) — it explains which PDFs convert well and what to check before you start.

| |
|---|
| **First time?** Start with a short, simple PDF (10 to 30 pages). You will see the whole process faster and learn what each step does before working with a full textbook. |

## Importing

When you create a new project, ADT Studio asks you for the PDF file and a name for the book. From that moment, everything related to this book — the source file, your settings, all generated content, all versions — lives inside a single project folder on your computer.

You can create as many projects as you want. Each one is independent.

## What happens next

Importing does not process anything yet. Your PDF is simply loaded and ready. The actual conversion begins with the next step: [Extract content](/docs/extract).
