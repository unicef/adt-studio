## Diseñado para inspirar confianza

La producción de libros accesibles suele ser lenta, manual y propensa a errores:
el contenido se vuelve a teclear, la estructura se pierde y los pasos quedan
repartidos entre herramientas que no se comunican entre sí. ADT Studio reúne
todo el proceso en un solo lugar, en torno a tres ideas innegociables.

<Principles />

## Transparencia por defecto

Cada prompt, cada respuesta y cada costo es algo que puedes abrir y leer. Cuando
un resultado parece incorrecto, puedes ver exactamente qué llamada lo produjo,
cambiar las entradas y volver a ejecutar: solo se recalcula el trabajo que
realmente cambió.
