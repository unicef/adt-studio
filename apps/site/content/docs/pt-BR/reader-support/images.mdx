Descrições longas usam o mesmo mapa de texto do restante da página. Para um nó de imagem, use a entrada de `texts.json` de seu `data-id`; depois use a descrição da página, `alt` ou `figcaption` como fallback.

A apresentação natural é uma caixa de luz ou zoom, onde há espaço para leitura. Mostre-a apenas quando `features.describeImages` for `true`.

## Variantes localizadas de imagem

`images.json` mapeia um id de imagem para um recurso de substituição quando a própria imagem contém conteúdo traduzido, como um diagrama rotulado. Na mudança de idioma, substitua o `src` dos nós de imagem correspondentes.

O mapa é opcional. `features.describeImages` pode ser `true` quando há descrições, mas não há recurso de imagem traduzido; mantenha o `src` original sempre que o mapa ou seu id estiver ausente.

Variantes existem para idiomas de destino, nunca para o idioma-fonte, então o mapa fica sob cada locale traduzido:

<PackageSnippet path="content/i18n/pt-BR/images.json" />

A chave é o `data-id` da `<img>`; o valor é um arquivo que fica ao lado do original em `images/`. Trocar para pt-BR significa substituir o `src` exatamente dessas seis imagens e deixar todas as outras intactas.

<PackageSnippet title="Configuração do recurso de descrição de imagem" path="assets/config.json" />

<Callout title="Um mapa vazio é válido">
A maioria dos livros não precisa de imagens traduzidas e envia `{}`. Mantenha a fonte original sempre que o mapa, ou o id de uma imagem dentro dele, estiver ausente.
</Callout>
