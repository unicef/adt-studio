and started, but real preview packaging failed on
`lightningcss.linux-arm64-musl.node`. A separate image built from unchanged
`develop` (`ef31494d`) reproduced the same error with an ESM import of
`@tailwindcss/postcss`. The build installed Debian/glibc dependencies and then
copied them into an Alpine/musl runtime. The combined image now uses Debian slim,
matching the build and API image, and installs Playwright's matching libraries.

Further packaged execution exposed the CSS virtual-input path assuming the
source layout and Docker omitting the already-declared `tw-animate-css` dependency.

Docker runtime includes that stylesheet package. A standalone bundled-process
test covers both export and preview CSS with dependencies beside the bundle.

latest historical row directly and rejected a SQL NULL invalidation marker.
It now uses the shared current-version reader. Its real-storage regression verifies
invalidation returns no active assessment and restoring the retained version makes

## Walkthrough and rollout notes

The synthetic book has four pages, stable text/image IDs, French manual and legacy
translations, manual Easy Read and captions, and a glossary item. Source edits in
the four examples were made through the real Save APIs and inspected in Studio.
The separate draft walkthrough exercised the actual textarea, Save conflict,
Keep, Regenerate choice and bulk controls. The Preview reader and web export
were exercised through their real UI. This is synthetic acceptance, not an
unreported user book or a paid-provider quality evaluation.

Final review found and fixed: canonical speech key ordering; fallback source
context mismatch; unknown-input protection; stable quiz options; late skip
publication; retained stage editors hidden by cleared job state; ID-prefix page
filtering/batching; Speech rerun implicitly invoking Translate; and disclosure
that ignored export feature eligibility. Regression evidence is recorded above.

The implementation reuses the published book writer admission protocol, and
coordinates authorship/review evidence with SPEC-0002 without claiming that
SPEC-0002 is implemented. See [reuse attribution](spec-0001-reuse.md).

Existing-book **full extraction/CLI reruns safely refuse with
`UNSAFE_RESUME_UNAVAILABLE`** until the separate extraction/resume prerequisite
can preserve source identity. This deliberately retains data and makes no
provider calls; it is not a claim that full CLI resumption is delivered here.
Normal catalog/enrichment stage actions use the shared mechanisms implemented
in this PR. Storyboard/Sectioning freshness and automatic regeneration of
glossary/quizzes/TOC remain the spec's explicit non-goals. Historical bytes already
destroyed by older releases cannot be reconstructed; downgrade support is not
claimed. New immutable assets remain inside the book and independent of caches.
