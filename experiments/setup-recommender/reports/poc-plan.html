Issue #333 · auto mode · proposal

Putting auto mode to the test

So far the engine ran on 6 excerpts and 2 whole books, the user was simulated, and no book was ever converted with the picks. To prove it, I want to build one test bench inside the real ADT Studio where every approach can be switched on, run on real books, and compared on the same scorecard.

What has to be proven
C1 · Right picks

On books it has never seen, it picks what your team picked, and never gets a locked setting wrong without asking.

C2 · Picks matter

Converting with its picks gives a better book than the defaults: no lost exercises, figures kept whole, spreads handled.

C3 · Cheap enough

The scan adds seconds, not minutes, even on a 400-page book, a slow laptop or a slow connection.

C4 · People get it

Real users understand each pick, fix the wrong ones, and finish faster than the manual wizard.

The test bench

One pipeline, two switches

Everything runs in the real app on this branch, behind a dev-only switch. The engine switch changes how the book is read; the flow switch changes how the picks are shown. Both read and write the same book settings, so any engine works with any flow.

Switch 2 · flows

Two ways to show the picks

Both follow the rule we agreed: the AI runs first, shows its picks, the user confirms or changes. Questions only when needed. Every pick shows what was picked, what it means in plain words, and why, with the pages it saw.

Sure / not sure, with a page preview

A real page of the book at the top. Below, picks split into "We're sure" (folded) and "Please check" (open, nothing pre-picked when only the opening pages were read).

Order

Three phases, starting with what needs nothing from you

1 · Build the bench

  • Engines E0–E3 as one module, run from a script and from a dev-only API route.
  • Picks saved with their reasons and pages, and the scan saved into the book.
  • Run T3 (time) and T6 (Extract reuse).
  • Run T2 on the PoC excerpts first.
Needs: nothing. Can start now.

2 · Unseen books

  • Run T1 on your converted books, no rule changes allowed during the run.
  • Run T4 on the same books with other providers.
  • Pick one engine from the results.
Needs: books, settings used, other provider keys.

3 · People

  • Flows A and B in the real Add Book screen, switchable from a dev toolbar.
  • Run T5 with the chosen engine.
  • Visual report with recordings and numbers.
Needs: 10 testers.
